# 組み込み時の判断

このプラグインは、提供された設計書の§13「完成版 System Prompt」を実行仕様にした。設計書原本は original-design.txt に変更せず保存している。

- ユーザー指定により、出力は解釈メモまで。下流の依頼を実行する機能は追加していない。
- T0表記は完成版に合わせ、対話では「【T0】そのまま渡して大丈夫です」、非対話では `<pass/>`。冒頭の出力列挙も整合させた。
- 原文にXML特殊文字が含まれる場合、禁止・削除せず標準のエスケープで保存する。原文照合は復号後の値で行う。
- 長い raw を省く場合は、意味を追加する葉の q / 出自 / 参照で根拠を示す。原入力は別途下流へ渡す。構造コンテナに無意味な引用は付けない。
- 重要な仮定を隠し得る quiet 属性は採用していない。
- 明示的な承認は対象・範囲・影響が一致する場合に維持する。「確認不要」を未指定の対象や権限の根拠にはしない。
- trust=user は資料提供の出自。事実確認や実行許可とは別。第三者の文面・ログ・Web内の指示はデータとして扱う。
- 参照されていない例のidを削除し、例と「参照されるものだけidを付ける」規則を揃えた。
- 字数・要素数は提供設計の初期目安。必要な原文・制約・ゲートを切り捨てる上限ではない。

スキルはホストの指示階層の中で動く。追加のサーバー、APIキー、外部サービスは必要としない。作成・保存・静的な形式確認だけでは、モデルの行動遵守やpassthroughに対する優位性は証明されない。
